# הדוגמה המאושרת לפורמט הפתרון

**השאלה (1987 שאלה 1):** כדור במסה 400 גרם מונח בגובה 7.2 m מעל הקרקע. הכדור נדחף על ידי כוח אופקי של 1000 N, הפועל עליו במשך 0.01 s. במרחק אופקי של 30.5 m מנקודת הזריקה עומד אדם. ברגע שהכוח מפסיק לפעול, האדם מתחיל לרוץ ממנוחה לעבר הכדור.

**דגש מהמחבר** (טריק בשם "הדרך להבדיל בין עבודה עם קינמטיקה לעבודה עם עבודה ואנרגיה"): כוח שנתון לפי זמן פותרים בקינמטיקה: מוצאים את התאוצה מהחוק השני של ניוטון, וממשיכים עם משוואות התנועה. כוח שנתון לפי מרחק פותרים בעבודה ואנרגיה.

**סעיף א: מה מהירות היציאה של הכדור?**

הסבר לפני הסעיף: הכוח נתון לפי זמן, 0.01 s, ולכן פותרים בקינמטיקה. קודם מוצאים את התאוצה מהחוק השני של ניוטון, ואחר כך את המהירות ממשוואת המהירות.

| מה עושים | למה | חישוב |
| --- | --- | --- |
| ממירים מסה לק״ג | הכוח נתון בניוטון, וניוטון מוגדר על ק״ג. בגרמים התאוצה תצא גדולה פי 1000 | m = 400 g = 0.4 kg |
| כותבים את החוק השני של ניוטון בכיוון האופקי | הכוח נתון לפי זמן, ולכן עובדים בקינמטיקה. החוק השני מחבר בין הכוח הנתון לתאוצה שצריך למצוא. בכיוון האופקי פועל רק כוח הדחיפה, כי הכובד אנכי | F = m · a |
| מבודדים את a | זה הנעלם היחיד במשוואה | a = F / m |
| מציבים F = 1000 ו-m = 0.4 | שני הנתונים כבר ביחידות הנכונות | a = 1000 / 0.4 |
| מחלקים | התאוצה עצומה, אבל היא פועלת רק מאית שנייה | a = 2500 m/s² |
| בוחרים את משוואת המהירות בתאוצה קבועה | ידועים התאוצה, הזמן והמהירות ההתחלתית, ומחפשים מהירות. זו המשוואה שמקשרת בדיוק את ארבעתם, בלי מקום | v = v₀ + a · t |
| מציבים v₀ = 0 ו-t = 0.01 | הכדור מונח לפני הדחיפה, והכוח פועל במשך 0.01 s | v = 0 + 2500 · 0.01 |
| כופלים | זו המהירות ברגע שהכוח מפסיק, כלומר מהירות היציאה. מעכשיו היא קבועה בכיוון האופקי | v = 25 m/s |

**תשובה סופית:** 25 m/s
