# הערות של הבעלים לטיפול בסוף

הבעלים מוסיף הערה בכל פעם שהוא כותב "הערה:". מטפלים בהן בסוף הפיתוח (או כשהבעלים מבקש), ומסמנים ✓ כשטופלו.

1. **תמחור המנוי:** הבעלים לא אוהב את צורת התמחור הנוכחית (150 ש"ח ל-3 חודשים בלבד). ליצור עוד כמה אופציות תמחור. (נרשם 2026-11-19)
2. ✓ **צבעי העיצוב:** הצבעים הכהים (צפחה וזהב) נותנים תחושה של "אתר השקעות מוזר". הבעלים רוצה צבע מרענן ולא מרדים. (נרשם 2026-11-19. טופל: נבחרה פלטת "מנטה ושמש")
