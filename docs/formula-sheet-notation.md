# סימונים לפי דף הנוסחאות במכניקה (משרד החינוך, 2027)

לשימוש בפתרונות: המשוואה שמציבים בה נרשמת בקטן בעמודת "מה עושים" בדיוק בסימונים האלה. (תמליל שלנו של הסימונים בלבד; הקובץ עצמו לא נשמר במאגר.)

## קינמטיקה
- מהירות ממוצעת: v̄ = Δx/Δt · מהירות רגעית: v = dx/dt
- תאוצה ממוצעת: ā = Δv/Δt · תאוצה רגעית: a = dv/dt
- תנועה שוות-תאוצה: v = v₀ + at · x = x₀ + v₀t + ½at² · x = x₀ + ((v₀ + v)/2)t · v² = v₀² + 2a(x − x₀)

## דינמיקה
- F = mg · F_sp = kΔℓ · f_s ≤ μ_s N · f_k = μ_k N · ΣF⃗ = ma⃗ · F⃗₁,₂ = −F⃗₂,₁ · ρ = m/V

## עבודה, אנרגיה והספק
- W = F_x Δx = F cosθ Δs · W = ∫F_x dx · E_k = ½mv² · U_G = mgh · U_sp = ½k(Δℓ)²
- W_כוללת = ΔE_k · W_לא משמרים = ΔE · W_כוח משמר = −ΔU · P̄ = W/Δt

## מתקף ותנע
- J⃗ = F⃗Δt · J⃗ = ∫F⃗dt · p⃗ = mv⃗ · J⃗_כולל = Δp⃗
- m_A v⃗_A + m_B v⃗_B = m_A u⃗_A + m_B u⃗_B · באלסטית חד-ממדית: v_A − v_B = −(u_A − u_B)

## תנועות מחזוריות ותנועה מעגלית
- ω = 2πf = 2π/T · ϖ = Δθ/Δt · v = 2πr/T = 2πrf · v = ωr · a_R = v²/r = ω²r

## תנועה הרמונית פשוטה
- ΣF⃗ = −cx⃗ · ω = √(c/m) · x = A cos(ωt + φ) · v = −ωA sin(ωt + φ) · v = ±ω√(A² − x²)
- a = −ω²A cos(ωt + φ) · a = −ω²x · T = 2π√(m/c) · T = 2π√(ℓ/g)

## כבידה
- (r̄₁/r̄₂)³ = (T₁/T₂)² · F = Gm₁m₂/r² · g* = GM/r² · U_G = −GMm/r (U_G(r→∞) = 0)
- לוויין במסלול מעגלי: E_k = GMm/2r = −U_G/2 · E = −GMm/2r
